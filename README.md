# RAG and Agentic AI Capstone Project
### This project is for completion of "IBM RAG and Agentic AI Professional Certificate" program on Coursera

The aim of the project is to build a complete, production-style generative AI system that integrates structured data processing, multimodal retrieval, multi-agent orchestration, and secure tool execution. It includes:
* transforming unstructured restaurant text and customer review images into structured JSON data and developing an interface to manage and update the knowledge base.
* design and implementing a multimodal retrieval system.
* constructing vector indexes, generating text and image embeddings, and building similarity-based retrieval workflows that incorporate metadata filtering and multi-based ranking to improve cross-modal results.
* developing a coordinated multi-agent recommendation system by defining specialized agent roles and integrating them into a unified workflow.
* exposing the system through an interactive chatbot interface that responds dynamically to user queries.
* integrating agents, retrieval systems, and tools using the Model Context Protocol by configure MCP servers, implementing clients and hosts, and validate end-to-end execution.

## Tools/Software used
* **Python** (for implementing AI workflows, command-line interfaces, and data processing)
* **LangChain** (for building and orchestrating AI agents)
* **LangGraph** (for visualizing and coordinating multi-agent workflows)
* **Gradio** (for building interactive chatbot interfaces)
* **IBM watsonx.ai** (for multimodal AI and LLM-based workflows)
* **FAISS** or similar vector database libraries (for constructing multimodal vector indexes)
* **MCP** (Model Context Protocol for integrating agents, tools, and retrieval systems)
* **Jupyter** Notebooks (for experimenting and running Python-based labs)
* **Git/GitHub** (for version control and managing project artifacts)
* **JSON** (for storing data in a coherent query-friendly format with a schema suitable for indexing and search)

### File names
